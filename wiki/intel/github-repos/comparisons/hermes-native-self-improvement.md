# Hermes-Native Self-Improvement Plugins

Dated reference-stack comparison: capability fit, overlap, and integration cost are judged for the workloads summarized below; recorded scores and verdicts retain their dated scope, not universal product rankings. See the [evaluation methodology](../../awesome-harness-engineering/methodology.md).

## Executive judgment

Keep both as watched pattern sources. Curator Evolver deserves deeper source tracking for reviewer-only mining and guarded application; Self-Improvement deserves lighter tracking for evidence packs and outcome accounting. Neither review establishes useful behavioral improvement or authorizes an automatic editor.

## Different contracts

- [Curator Evolver](../repos/pingchesu--hermes-curator-evolver.md): local hook evidence, heuristic review queue, bounded managed notes, optional variants, hash-bound application, backups and main-file rollback. Bootstrap enables a separate daily scheduler. External skill trees are not unattended mutation targets. Configured verification can be absent; support files and concurrent writes need stronger recovery than the main-file guard supplies.
- [Self-Improvement](../repos/ryonakae--hermes-self-improvement.md): wider runtime signals, evidence bundles, planner/editor/evaluator/calibrator roles, official skill/memory mutations and outcome ledgers. More expressive, but greater authority/provider surface; general rollback is absent and the inspected GEPA path reuses training examples as validation.

## Transferable sequence

Observed recurring failure → compact redacted evidence with provenance → exact target/owner → proposed bounded change → independently discriminating held-out behavior check → authorized source delivery → verified activation → outcome observation and reversible recovery.

Evidence review queues must not silently become canonical task state. Structural validation, prettier instructions, local variant scores and successful file writes do not prove better execution. Exact target hashes guard stale input, not concurrent write atomicity.
