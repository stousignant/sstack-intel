# HarnessRouter/harnessrouter
## Quick take
HarnessRouter is a high-value reference for exposing heterogeneous coding harnesses through one self-hosted protocol and API.
## Score
**86/100**
- **Harness relevance — 29/30:** Its main purpose is running and controlling multiple agent harnesses through one interface.
- **Practical pattern value — 23/25:** Unified lifecycle and failure semantics are directly transferable to multi-harness control planes.
- **Evidence and maturity — 14/20:** The active README is detailed and documents releases and deployment, but the repository is only about a month old.
- **Novelty — 14/15:** An open protocol spanning heterogeneous harnesses is an unusually differentiated integration layer.
- **Risk-adjusted accessibility — 6/10:** Apache-2.0 and one-container setup help, while roughly 4 GB, Docker, keys, and bundled CLIs add cost.
## Why it matters
- UHP normalizes sessions, streaming, files, cancellation, and failures across multiple harnesses.
- The self-hosted control plane illustrates provider-key and local-data boundaries.
## Caveat
The project is very new, and evaluation requires a large container, provider credentials, and third-party harness installations.
