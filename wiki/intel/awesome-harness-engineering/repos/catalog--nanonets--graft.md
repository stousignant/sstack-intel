# NanoNets/Graft
## Quick take
Graft supplies coding agents with a regenerable structural code graph, prompt-time context, and dependency blast-radius signals.
## Score
**79/100**

- **Practical pattern value — 21/25:** Regenerable local graphs, preserved user notes, dry-run wiring, refresh hooks, and blast-radius context transfer well.
- **Evidence and maturity — 14/20:** The active MIT project documents CI-oriented behavior, benchmarks, SWE-bench results, and broad integrations but is new.
