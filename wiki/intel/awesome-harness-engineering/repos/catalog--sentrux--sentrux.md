# sentrux/sentrux
## Quick take
A Rust architecture sensor that exposes structural health, rules, dependency views, and test gaps to agents through MCP and CI.
## Score
**69/100**
- **Harness relevance — 22/30:** Architectural scans, rules, test-gap signals, and MCP feedback form a substantial agent verification component.
- **Practical pattern value — 19/25:** Codified architecture constraints, incremental rescans, CI enforcement, and agent-readable health signals are reusable.
- **Evidence and maturity — 9/20:** The MIT project documents a single binary, MCP tools, and language coverage, but has a short public activity history.
- **Novelty — 11/15:** It combines architecture visualization, quality scoring, rule enforcement, and agent feedback in one sensor.
- **Risk-adjusted accessibility — 8/10:** A permissive single Rust binary with no runtime dependencies is easy to try, though metric meaning needs validation.
## Why it matters
- Turns architectural expectations into machine-checkable feedback during agent work.
- Its sensor model keeps generation separate from verification and human governance.
## Caveat
The project has a short public history, and its quality scores, broad language support, and improvement claims were not independently evaluated.
