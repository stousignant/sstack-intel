# ComposioHQ/composio
## Quick take
Composio supplies a cross-framework tool, authentication, and session layer for action-taking agents.
## Score
**78/100**
- **Harness relevance — 20/30:** Tool discovery, authentication, sessions, triggers, and sandboxing are substantial agent-harness capabilities.
- **Practical pattern value — 23/25:** Per-user sessions and runtime tool discovery are directly reusable patterns for controlling context and credentials.
- **Evidence and maturity — 18/20:** Active SDKs, multiple language packages, provider adapters, tests, documentation, and MIT licensing are strong signals.
- **Novelty — 10/15:** The combination of broad tool coverage, managed authentication, and context-aware discovery is distinctive.
- **Risk-adjusted accessibility — 7/10:** MIT SDKs and quickstarts help, but core examples require a Composio account, API key, and connected services.
## Why it matters
- Its session model scopes tools and connected accounts per user rather than exposing one global integration surface.
- Runtime tool discovery avoids loading hundreds of definitions into an agent's context.
