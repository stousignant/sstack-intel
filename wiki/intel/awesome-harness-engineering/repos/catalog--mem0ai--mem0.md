# mem0ai/mem0
## Quick take
Mem0 provides persistent user, session, and agent memory with extraction, linking, and hybrid retrieval.
## Score
**82/100**
- **Harness relevance — 20/30:** Provides a substantial persistent-memory layer for assistants and agents.
- **Practical pattern value — 25/25:** Extraction, entity linking, hybrid retrieval, temporal ranking, and scoped memories are directly transferable.
- **Evidence and maturity — 20/20:** The active Apache-2.0 project documents packages, self-hosting, managed service options, benchmarks, and integrations.
- **Novelty — 10/15:** Its multi-signal and temporal memory pipeline is a distinctive combination of established retrieval techniques.
- **Risk-adjusted accessibility — 7/10:** Packages and a self-hosted path are available, but defaults require model and embedding providers and managed results differ from OSS.
## Why it matters
- Offers SDK, self-hosted, and managed deployment paths for the same memory boundary.
- Publishes an evaluation framework and documents temporal and entity-aware retrieval.
## Caveat
The reported benchmark scores use proprietary managed-platform optimizations, so the README says open-source users should not expect identical results.
