# shareAI-lab/learn-claude-code
## Quick take
A progressive 17-lesson implementation course that builds a Claude-Code-like harness from a basic loop to evaluated goal execution.
## Score
**90/100**
- **Harness relevance — 30/30:** The repository is explicitly a progressive course in building real coding-agent harnesses.
- **Practical pattern value — 25/25:** Seventeen lessons cover loops, tools, permissions, hooks, planning, subagents, compaction, memory, isolation, and goal evaluation.
- **Evidence and maturity — 14/20:** The active MIT project provides multilingual documentation, runnable examples, a web platform, and a full lesson track.
- **Novelty — 12/15:** Its staged path from a tiny Bash-capable loop to workflow and goal runtimes is a distinctive teaching structure.
- **Risk-adjusted accessibility — 9/10:** Python examples and clear progression are approachable, though the current track requires an Anthropic API key.
## Why it matters
- Makes each harness capability inspectable in sequence instead of hiding the whole design behind a framework.
- Covers the path from tools and permissions through compaction, memory, worktree isolation, workflows, and independent evaluation.
## Caveat
It is an educational implementation rather than evidence of production readiness, and the current examples depend on Anthropic access.
