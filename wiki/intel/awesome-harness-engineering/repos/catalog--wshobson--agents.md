# wshobson/agents
## Quick take
A large multi-harness marketplace that projects one plugin source into native artifacts for five coding-agent ecosystems.
## Score
**81/100**
- **Harness relevance — 20/30:** The marketplace supplies substantial agent, skill, command, and plugin content for several coding harnesses.
- **Practical pattern value — 25/25:** A single source transformed into harness-native registries and artifacts is a directly transferable distribution and projection pattern.
- **Evidence and maturity — 14/20:** The README documents a large active catalog, installation paths, quality evaluation, security integrations, and MIT licensing.
- **Novelty — 15/15:** Producing idiomatic artifacts for five harnesses from one source rather than lowest-common-denominator output is unusually differentiated.
- **Risk-adjusted accessibility — 7/10:** MIT licensing and native marketplace installs ease sampling, while the very large third-party automation corpus increases review and supply-chain burden.
## Why it matters
- Demonstrates cross-harness distribution without forcing every target into one lowest-common-denominator format.
