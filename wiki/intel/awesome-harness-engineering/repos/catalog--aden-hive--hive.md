# aden-hive/hive
## Quick take
A production-oriented multi-agent harness centered on a persistent Queen that dynamically clones workers and coordinates them through shared state.
## Score
**86/100**
- **Harness relevance — 29/30:** Core runtime for persistent multi-agent colonies with orchestration, state, recovery, oversight, and cost controls.
- **Practical pattern value — 23/25:** Shared ledgers, persistent plans, worker cloning, park/resume, and scoped memory are directly reusable harness patterns.
- **Evidence and maturity — 15/20:** Active Apache-2.0 project with setup instructions and extensive documentation, but it is still young.
- **Novelty — 12/15:** The one-loop-controlling-many-loops colony model is a distinctive orchestration combination.
- **Risk-adjusted accessibility — 7/10:** Self-hosting and model flexibility help evaluation, while the workspace setup and broad runtime surface add weight.
## Why it matters
- Its crash-safe colony model is a concrete alternative to statically compiled agent graphs.
- The ledger, plan, oversight, and cost-control surfaces cover several recurrent long-running-agent failure modes.
## Caveat
README claims broad production capability, but this review did not run the system or verify reliability at scale.
