# google/adk-python
## Quick take
A full code-first agent framework with deterministic workflows, structured delegation, tools, evaluation, human confirmation, and deployment paths.
## Score
**92/100**
- **Harness relevance — 30/30:** Agents, graph workflows, task delegation, tools, state, evaluation, human confirmation, and deployment are core harness functions.
- **Practical pattern value — 24/25:** Deterministic workflow nodes, task contracts, tool confirmation, and code-first composition are directly transferable.
- **Evidence and maturity — 20/20:** Google maintains stable packages, CI, documentation, samples, regular releases, and multiple language implementations.
- **Novelty — 10/15:** The integrated task and workflow APIs are distinctive, while graph orchestration and tool ecosystems are established.
- **Risk-adjusted accessibility — 8/10:** Apache-2.0 licensing, PyPI installation, and local tooling help, but 2.0 carries documented breaking schema changes.
## Why it matters
- Combines agent autonomy with graph-defined routing, retries, state, and human gates.
- Its task API offers a concrete contract for controlled multi-agent delegation.
## Caveat
The 2.0 release documents breaking agent, event, and session changes, and Google-optimized integrations may not transfer uniformly to other stacks.
