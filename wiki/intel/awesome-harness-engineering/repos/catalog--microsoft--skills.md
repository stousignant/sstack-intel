# microsoft/skills
## Quick take
A large, tested catalog of Microsoft and Azure skills with agent templates, plugins, MCP configuration, and skill evals.
## Score
**82/100**
- **Harness relevance — 20/30:** Skills, agents, instruction templates, MCP configuration, and evals are substantial harness inputs.
- **Practical pattern value — 24/25:** The large cross-language catalog and acceptance-criteria test harness provide directly reusable patterns.
- **Evidence and maturity — 19/20:** Microsoft maintains an active MIT repository with CI, documentation, plugins, and 1,169 stated test scenarios.
- **Novelty — 10/15:** It combines SDK-grounding skills with mock evals, Ralph iteration, plugins, agents, and MCP templates.
- **Risk-adjusted accessibility — 9/10:** MIT and one-command selective installation help, though most content targets Microsoft and Azure stacks.

- Demonstrates acceptance-criteria-driven testing for a large multi-language skill corpus.
- Packages domain knowledge selectively to reduce context loading and cross-skill interference.
