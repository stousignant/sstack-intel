# stablyai/orca
## Quick take
Orca is a desktop and mobile agent workspace for coordinating parallel coding agents, worktrees, terminals, tasks, and reviews.
## Score
**86/100**
- **Harness relevance — 28/30:** Orchestrates fleets of coding agents through worktrees, terminals, tasks, review, remote hosts, and automation.
- **Practical pattern value — 21/25:** Parallel worktrees, snapshots, task-to-worktree flow, diff annotations, SSH worktrees, and CLI control are reusable.
- **Evidence and maturity — 17/20:** The active MIT project ships frequent releases, desktop and mobile builds, documentation, signed builds, and broad agent support.
- **Novelty — 11/15:** Integrates familiar terminal, worktree, task, review, mobile, and computer-use surfaces into one agent workspace.
- **Risk-adjusted accessibility — 9/10:** Packaged desktop builds and Homebrew installation ease evaluation despite broad host and remote-control capabilities.
## Why it matters
- It makes worktree isolation and task-to-branch workflows first-class interaction objects.
- CLI automation, SSH worktrees, snapshots, and diff annotations connect orchestration with recovery and review.
## Caveat
Frequent shipping and a very broad desktop, mobile, SSH, integration, and computer-use surface make README-level review insufficient for security or stability conclusions.
