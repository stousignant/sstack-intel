# QwenLM/Qwen-MM-Plugins
## Quick take
A modular skill-and-MCP suite that adds native image, video, audio, document, search, and specialist media capabilities to agent harnesses.
## Score
**80/100**
- **Harness relevance — 23/30:** Installable skills and MCP servers add substantial multimodal perception and media tooling to many agent harnesses.
- **Practical pattern value — 22/25:** Independent capability packages, shared configuration, immutable tags, verification actions, and native-model routing are reusable.
- **Evidence and maturity — 15/20:** The active institutional project documents installation, dependencies, testing, rollback, cookbooks, and broad harness coverage.
- **Novelty — 13/15:** It packages native visual, audio, document, CAD, and long-video workflows behind a consistent skill-plus-MCP model.
- **Risk-adjusted accessibility — 7/10:** Apache-2.0 licensing and local core tools help, while cloud keys and large system applications burden advanced capabilities.
## Why it matters
- Shows a clean capability packaging model with independent versions and shared cross-harness configuration.
- Lets multimodal models consume media natively instead of forcing every workflow through ad hoc shell conversion.
## Caveat
Advanced capabilities require provider credentials or heavy applications such as Blender, FreeCAD, Node, and ffmpeg, and harness setup paths vary.
