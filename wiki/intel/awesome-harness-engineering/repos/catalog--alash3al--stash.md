# alash3al/stash
## Quick take
A self-hostable MCP memory layer that turns agent episodes into structured facts, relationships, and longer-lived patterns in Postgres.
## Score
**67/100**
- **Harness relevance — 20/30:** Persistent memory and consolidation are substantial harness components rather than a full agent runtime.
- **Practical pattern value — 18/25:** The episodic-to-fact consolidation pipeline and MCP interface offer reusable state-management patterns.
- **Evidence and maturity — 12/20:** README documentation and active public metadata support an implemented project, but evidence is comparatively young.
- **Novelty — 10/15:** A staged cognitive consolidation pipeline is a distinctive memory-layer combination.
- **Risk-adjusted accessibility — 7/10:** Apache-2.0 and Docker Compose help evaluation, while Postgres, models, and hosted/local choices add setup weight.
## Why it matters
- Provides a concrete incremental consolidation pipeline for durable agent memory.
- Separates a reusable memory service from any particular MCP-compatible harness.
## Caveat
Evaluation requires database and model infrastructure, and the hosted beta explicitly differs from the open-source codebase.
