# withastro/flue
## Quick take
Flue is a programmable TypeScript harness for composing autonomous agents from models, tools, skills, state, and sandboxes.
## Score
**87/100**

- **Practical pattern value — 23/25:** Function-composed agent dependencies and interchangeable local or remote sandboxes are directly reusable patterns.
- **Evidence and maturity — 14/20:** The active institutional project has clear documentation, package boundaries, examples, and Apache-2.0 licensing.
