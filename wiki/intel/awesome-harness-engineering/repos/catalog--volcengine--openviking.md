# volcengine/OpenViking
## Quick take
A context database that exposes agent memory, knowledge, and skills as a tiered, observable virtual filesystem.
## Score
**84/100**
- **Harness relevance — 27/30:** Hierarchical memory, knowledge, skills, retrieval trajectories, and context loading are central harness context functions.
- **Practical pattern value — 22/25:** Virtual-filesystem navigation, tiered summaries, on-demand loading, and observable retrieval trajectories are reusable.
- **Evidence and maturity — 16/20:** The active institutional project documents deployment, benchmarks, reproduction scripts, integrations, and a versioned release.
- **Novelty — 14/15:** A debuggable virtual filesystem unifying memory, RAG resources, and skills is an unusually differentiated context model.
- **Risk-adjusted accessibility — 5/10:** A quick start and hosted playground help, but AGPL licensing, provider setup, and database operations raise integration cost.
## Why it matters
- Makes context retrieval navigable and debuggable instead of hiding it behind an opaque vector query.
- Its L0-to-L2 hierarchy offers a concrete progressive-disclosure pattern for memory and resources.
## Caveat
Benchmark gains are README claims tied to named models and setups, while AGPL licensing and provider-backed deployment increase evaluation and integration cost.
