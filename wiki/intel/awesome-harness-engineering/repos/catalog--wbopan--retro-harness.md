# wbopan/retro-harness
## Quick take
Retro Harness is an unusually relevant research reference for improving skills and instructions from unlabeled historical agent trajectories.
## Score
**88/100**
- **Harness relevance — 29/30:** Directly optimizes an agent harness made of skills, tools, workflows, and instruction files.
- **Practical pattern value — 22/25:** Trajectory mining, candidate comparison, and held-out grading form a reusable improvement loop.
- **Evidence and maturity — 15/20:** MIT project includes a paper, hermetic and real-agent tests, runnable workflows, and reported SWE-bench results.
- **Novelty — 15/15:** Self-supervised retrospective harness optimization without labels is unusually differentiated.
- **Risk-adjusted accessibility — 7/10:** MIT licensing and stdlib Codex tooling help, but model costs, session sensitivity, and evaluation setup add risk.
## Why it matters
- Its self-preference loop avoids requiring a curated validation set for every harness change.
- The Codex and Claude workflows show how retrospective optimization can target existing project instructions.
## Caveat
The reported SWE-bench gain comes from the authors’ experiment, and running the workflow sends historical sessions through model-driven analysis.
