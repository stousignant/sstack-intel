# GammaLabTechnologies/harmonist
## Quick take
Harmonist packages a portable multi-agent workflow whose hooks block completion when required protocol evidence is absent.
## Score
**91/100**
- **Harness relevance — 30/30:** Provides a multi-agent coding harness with mechanically enforced review, memory, and supply-chain gates.
- **Practical pattern value — 25/25:** Hook-enforced completion, validated memory, specialist routing, and integrity checks are directly transferable.
- **Evidence and maturity — 14/20:** The active MIT project documents CI, a large agent catalog, architecture, testing, and integration procedures.
- **Novelty — 15/15:** Enforcing protocols mechanically instead of relying on prompt compliance is unusually differentiated.
- **Risk-adjusted accessibility — 7/10:** It has no runtime dependencies, but integration is prompt-driven and spans many generated agents and hooks.
## Why it matters
- Turns reviewer dispatch, memory updates, and shipped-file integrity into mechanical gates.
- Uses schema validation and correlation IDs to constrain agent-authored memory.
## Caveat
The broad 193-agent catalog and prompt-led integration can add substantial policy surface that must be audited for each target repository.
