# vercel/eve
## Quick take
A filesystem-first TypeScript framework for durable agents, with conventional folders as its main authoring interface.
## Score
**88/100**
- **Harness relevance — 29/30:** Tools, skills, channels, schedules, subagents, and durable execution make eve a core harness framework.
- **Practical pattern value — 23/25:** Its conventional filesystem layout and typed tool modules are directly transferable.
- **Evidence and maturity — 15/20:** Vercel maintains an active Apache-2.0 npm package with documentation, but labels the framework beta.
- **Novelty — 13/15:** The filesystem itself is the authoring interface for prompts, tools, skills, channels, and schedules.
- **Risk-adjusted accessibility — 8/10:** One-command scaffolding is easy, though beta terms and gateway model access add risk.
## Why it matters
- Makes an agent inspectable through plain files for instructions, tools, skills, channels, and schedules.
- Provides a small scaffold that can grow into human-in-the-loop, subagent, and recurring workflows.
## Caveat
Eve is in beta and its APIs, documentation, and behavior may change before general availability.
