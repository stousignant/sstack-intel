# awslabs/agentcore-samples
## Quick take
This is a large educational and reference corpus for assembling agents on Amazon Bedrock AgentCore.
## Score
**59/100**
- **Harness relevance — 20/30:** The examples cover substantial runtime, memory, identity, tools, observability, evaluation, and policy components.
- **Practical pattern value — 17/25:** Structured samples and templates provide reusable patterns, though many are coupled to AgentCore services.
- **Evidence and maturity — 14/20:** AWS ownership, active documentation, and broad samples support an active documented-project anchor.
- **Novelty — 5/15:** The repository packages established managed-agent patterns rather than a notably new harness design.
- **Risk-adjusted accessibility — 3/10:** Apache-2.0 code is inspectable, but meaningful evaluation depends heavily on AWS services and credentials.
## Why it matters
- Maps production-oriented examples across runtime, gateway, identity, memory, evaluation, policy, and telemetry.
- Includes end-to-end samples and infrastructure templates for several agent frameworks.
## Caveat
Most patterns are service-specific, and the repository is migrating older Starter Toolkit samples to the AgentCore CLI.
