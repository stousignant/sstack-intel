# microsoft/autogen
## Quick take
An influential layered framework for event-driven and conversational multi-agent systems that now serves primarily as a maintained legacy reference.
## Score
**85/100**
- **Harness relevance — 30/30:** AutoGen implements core single- and multi-agent runtimes, tools, messaging, and orchestration.
- **Practical pattern value — 22/25:** Layered APIs, event-driven runtimes, agent-as-tool composition, and MCP workbenches remain reusable patterns.
- **Evidence and maturity — 17/20:** Institutional history, releases, and extensive docs are strong, but the project is now community-managed maintenance mode.
- **Novelty — 9/15:** Its layered cross-language multi-agent design was influential but is no longer unusually novel.
- **Risk-adjusted accessibility — 7/10:** Package installation is straightforward, but maintenance status and split content/code licenses reduce accessibility.
## Why it matters
- Documents clear separation between low-level runtimes, opinionated AgentChat APIs, extensions, and prototyping UI.
- Agent-as-tool and MCP workbench examples remain useful orchestration references.
## Caveat
AutoGen is in maintenance mode, directs new users to Microsoft Agent Framework, and applies different licenses to documentation and code.
