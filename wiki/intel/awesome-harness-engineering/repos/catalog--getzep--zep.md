# getzep/zep
## Quick take
The integration and examples layer for Zep Cloud, useful for studying cross-framework agent memory, ingestion, and memory evaluation.
## Score
**67/100**
- **Harness relevance — 20/30:** Agent memory, retrieval integrations, and evaluation are substantial harness components, but this repository is not the product runtime.
- **Practical pattern value — 19/25:** Framework adapters, ingestion pipelines, ontologies, memory benchmarks, and an evaluation harness offer reusable integration patterns.
- **Evidence and maturity — 14/20:** Active Apache-2.0 examples repository backed by official SDKs, while core Zep is managed and the old community edition is deprecated.
- **Novelty — 8/15:** Combining temporal knowledge-graph memory with broad agent-framework integrations is distinctive but not unique.
- **Risk-adjusted accessibility — 6/10:** Examples are accessible, but meaningful use depends on Zep Cloud and deprecated local code should not be treated as supported.
## Why it matters
- Its framework-first adapters show how one memory substrate can serve heterogeneous agent runtimes.
- The included ingestion and benchmark surfaces connect memory construction to retrieval evaluation.
## Caveat
This repository is explicitly not the Zep product; current use depends on the managed service, and the bundled Community Edition is deprecated and unsupported.
