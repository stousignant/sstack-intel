# codejunkie99/agentic-stack
## Quick take
A portable agent directory that carries memory, skills, permissions, telemetry, and bounded-loop protocols across many harnesses.
## Score
**87/100**
- **Harness relevance — 29/30:** Portable memory, skills, permissions, adapters, bounded loops, and review tooling cover most agent-harness layers.
- **Practical pattern value — 23/25:** Owned worktrees, finite loop budgets, staged lesson review, safe upgrades, and adapter manifests are reusable.
- **Evidence and maturity — 15/20:** The active project documents releases, migrations, diagnostics, lifecycle commands, and explicit beta boundaries, but is young.
- **Novelty — 13/15:** A single portable agent directory joins cross-harness memory, skills, telemetry, review, and bounded-loop contracts.
- **Risk-adjusted accessibility — 7/10:** Apache-2.0 licensing and local scripts help, while broad filesystem and harness configuration changes demand careful review.
## Why it matters
- Its reviewed lesson lifecycle and safe-upgrade ownership rules address common durable-memory hazards.
- The bounded-loop contract combines budgets, worktree isolation, checkpoints, and deterministic verification.
## Caveat
The supervisor is explicitly not an OS sandbox, several surfaces are beta, and installation modifies multiple harness-specific configuration paths.
