# QoderAI/better-harness
## Quick take
A cross-host harness-analysis workflow that turns project and session evidence into bounded findings, repair plans, and explicit validation routes.
## Score
**91/100**
- **Harness relevance — 30/30:** Directly analyzes and improves the task-to-delivery loop around coding agents across multiple hosts.
- **Practical pattern value — 24/25:** Evidence collection, five-dimensional diagnosis, scoped findings, host adapters, paired reports, and longitudinal comparison are directly transferable.
- **Evidence and maturity — 14/20:** Active MIT project has detailed docs, sample reports, collectors, and multiple adapters, but is young and host coverage varies.
- **Novelty — 14/15:** Treating the full work episode rather than only the final diff as the evaluation unit is unusually differentiated.
- **Risk-adjusted accessibility — 9/10:** Plugin-based installation and read-only analysis lower risk, though setup and evidence coverage differ by host.
## Why it matters
- It keeps configured capability separate from evidence that a mechanism was actually used during a task.
- Its five-part Agent Work Loop is a practical schema for diagnosing failures before execution through delivery and learning capture.
## Caveat
A generated report establishes only what its available evidence supports; missing sessions, host-adapter differences, and later outcome data limit causal improvement claims.
