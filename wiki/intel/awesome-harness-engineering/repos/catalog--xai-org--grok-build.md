# xai-org/grok-build
## Quick take
The source release of a full coding-agent harness spanning terminal UI, tools, workspaces, automation, and editor embedding.
## Score
**88/100**
- **Harness relevance — 30/30:** The repository contains a coding-agent runtime, tools, workspace layer, headless mode, ACP, and TUI.
- **Practical pattern value — 22/25:** Its separated Rust crates and shared interactive, headless, and editor entry points provide reusable architecture.
- **Evidence and maturity — 18/20:** The institutional Apache-2.0 source mirror has released binaries, detailed docs, build instructions, and per-crate test commands.
- **Novelty — 11/15:** A full-screen mouse TUI, long-running tasks, headless automation, ACP, skills, plugins, and sandboxing form a distinctive package.
- **Risk-adjusted accessibility — 7/10:** Prebuilt binaries help, but authentication is required and source builds need Rust, DotSlash, and generated workspace constraints.
## Why it matters
- Offers a concrete crate decomposition between composition root, runtime, tools, workspace, and user interface.
- Supports the same harness interactively, headlessly for scripts or CI, and through ACP editors.
## Caveat
The tree is periodically synced from a private monorepo, external contributions are closed, and some vendored tool implementations retain separate licenses.
