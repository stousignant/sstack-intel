# Tencent/TencentDB-Agent-Memory
## Quick take
A team memory hub that converts conversations, documents, and code into governed chat memory, skills, wiki pages, and code graphs shared across agents.
## Score
**80/100**
- **Harness relevance — 25/30:** Provides shared memory, skills, wiki, and code-graph context services used across agent harnesses.
- **Practical pattern value — 22/25:** Layered memory extraction, reviewed skill promotion, ACLs, framework-neutral proxying, imports, and role-specific loadouts are transferable.
- **Evidence and maturity — 15/20:** Active institutional project with installation and migration documentation, but the beta is evolving quickly and license evidence is not asserted.
- **Novelty — 13/15:** Unifying conversation memory, skills, linked documentation, and code graphs under governed team distribution is distinctive.

- Its human-reviewed promotion and per-asset ownership, visibility, and agent bindings are useful memory-governance patterns.
