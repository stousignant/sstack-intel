# topoteretes/cognee
## Quick take
Cognee builds persistent agent memory from documents, code, and sessions using graph and retrieval pipelines.
## Score
**82/100**
- **Harness relevance — 20/30:** Provides a substantial long-term memory and context subsystem for agents.
- **Practical pattern value — 25/25:** Graph, vector, code, session, distillation, and feedback flows are directly transferable memory patterns.
- **Evidence and maturity — 20/20:** The active Apache-2.0 project documents packages, deployment options, research, benchmarks, plugins, and integrations.
- **Novelty — 10/15:** Unifying session memory, knowledge graphs, code graphs, and routed retrieval is a distinctive combination.
- **Risk-adjusted accessibility — 7/10:** A no-key demo is easy to try, but real processing needs model infrastructure and some Postgres graph capability is demo-only.
## Why it matters
- Separates fast session memory from durable graph-backed knowledge and accepted lesson distillation.
- Supports plugins and MCP connections for carrying memory across agent runs.
## Caveat
The default configuration makes model and embedding calls, and the README says its all-in-Postgres graph store is demo-only unless using the licensed production feature.
