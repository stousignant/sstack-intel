# Gentleman-Programming/engram
## Quick take
A local-first persistent memory service with a deliberate save protocol and interfaces for many coding agents.
## Score
**79/100**

- **Practical pattern value — 25/25:** Curated saves, progressive retrieval, stable topic keys, review tools, and session summaries are directly transferable memory patterns.
- **Evidence and maturity — 14/20:** The README documents stable releases, broad client support, installation guides, and a maintained memory protocol.
- **Novelty — 10/15:** A zero-dependency local binary combining SQLite FTS5, MCP, HTTP, CLI, and TUI is a distinctive package.
- **Risk-adjusted accessibility — 10/10:** MIT licensing, one binary, one local database, and no required Node.js, Python, or Docker make evaluation low friction.
