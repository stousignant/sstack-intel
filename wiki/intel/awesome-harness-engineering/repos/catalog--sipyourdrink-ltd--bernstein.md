# sipyourdrink-ltd/bernstein
## Quick take
A deterministic governance and orchestration layer for agent fleets, with isolated worktrees and replayable audit evidence.

- **Practical pattern value — 25/25:** Declarative DAGs, atomic task claims, isolated worktrees, merge gates, signed receipts, replay, and audit evidence packs are directly transferable.
- **Evidence and maturity — 14/20:** The README documents CI, CodeQL, packages, 40-plus adapters, extensive guides, and active releases, while explicitly labeling the project beta and solo-maintained.
