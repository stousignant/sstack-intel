# Kaelio/ktx
## Quick take
ktx builds and serves governed warehouse and business context so data agents can query with approved semantics.
## Score
**68/100**
- **Harness relevance — 20/30:** Provides an executable context and semantic layer for data-analysis agents.
- **Practical pattern value — 17/25:** Approved metrics, join graphs, contradiction review, and CLI/MCP retrieval are reusable context patterns.
- **Evidence and maturity — 14/20:** The active Apache-2.0 project documents installation, tests, data mapping, telemetry, and agent integrations.
- **Novelty — 10/15:** Combining warehouse semantics, wiki knowledge, and self-improving agent context is distinctive.
- **Risk-adjusted accessibility — 7/10:** The CLI is packaged and read-only by design, but useful setup requires warehouse access and LLM or local-agent credentials.
## Why it matters
- Maps tables and joins while preserving reusable metric definitions.
- Exposes the combined context through both CLI and MCP interfaces.
## Caveat
Evaluation requires access to organizational data plus an LLM key or supported local agent login, and the tool collects privacy-conscious usage telemetry.
