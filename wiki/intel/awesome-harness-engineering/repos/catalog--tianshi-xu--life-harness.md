# Tianshi-Xu/Life-Harness
## Quick take
A research implementation that converts recurring deterministic-agent failures into reusable runtime interface interventions.
## Score
**84/100**
- **Harness relevance — 29/30:** Adapts runtime interface layers around frozen agents in deterministic environments.
- **Practical pattern value — 21/25:** Action realization, environment contracts, trajectory regulation, and procedural skills form reusable intervention classes.
- **Evidence and maturity — 13/20:** The MIT code release documents a paper, evolution prompts, seven benchmarks, and eighteen model backbones but is new.
- **Novelty — 15/15:** Evolving the harness from recurring failures while keeping model and environment fixed is unusually differentiated.
- **Risk-adjusted accessibility — 6/10:** Code and quickstarts are present, but separate benchmark families and dependencies make evaluation nontrivial.
## Why it matters
- Separates action realization, environment contracts, trajectory regulation, and procedural skill layers for targeted adaptation.
- Keeps model weights and benchmark environments fixed so improvements are attributed to the harness interface.
## Caveat
The reported gains across benchmarks and models were not reproduced, and the two benchmark families carry separate environment dependencies.
