# thClaws/thClaws
## Quick take
A native Rust harness whose shared engine serves desktop, interactive CLI, headless automation, and web operation with many providers.
## Score
**84/100**
- **Harness relevance — 30/30:** One engine provides agent loops, sessions, tools, skills, MCP, teams, schedules, plugins, and four execution surfaces.
- **Practical pattern value — 22/25:** A shared engine across GUI, CLI, headless, and web modes plus open instruction and skill standards is reusable.
- **Evidence and maturity — 14/20:** The active Apache-licensed Rust project documents builds, tests, releases, binaries, and many providers, but is young.
- **Novelty — 12/15:** Combining desktop, terminal, automation, and web operation with teams and scheduling in one binary is distinctive.
- **Risk-adjusted accessibility — 6/10:** Prebuilt binaries and open licensing help, while the expansive provider, web, plugin, secret, and scheduler surface raises risk.
## Why it matters
- Demonstrates how one agent, session, and tool core can support several operator surfaces.
- Uses portable AGENTS.md, SKILL.md, and MCP conventions alongside teams and background work.
## Caveat
The unusually broad provider, plugin, web, scheduling, secrets, and media surface was not security-reviewed or executed.
