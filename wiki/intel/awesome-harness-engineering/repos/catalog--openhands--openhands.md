# OpenHands/OpenHands
## Quick take
A self-hosted developer control plane for running multiple coding-agent backends and event-driven automations across local, container, remote, and cloud environments.

- **Practical pattern value — 25/25:** Backend switching, ACP compatibility, event-triggered automation, and multi-repository responsibility boundaries are directly transferable.
- **Evidence and maturity — 20/20:** Long-lived active metadata, CI, releases, extensive docs, and institutional stewardship provide strong maturity evidence.
- **Novelty — 11/15:** A backend-agnostic control plane spanning local, remote, and cloud agents is a distinctive combination.
