# Hmbown/CodeWhale
## Quick take
A provider-neutral Rust coding-agent harness with explicit approval modes, durable work organization, reversible snapshots, and extensible roles.
## Score
**85/100**
- **Harness relevance — 29/30:** A full local coding-agent harness with editing, command execution, sessions, goals, models, MCP, hooks, roles, and approvals.
- **Practical pattern value — 22/25:** Visible approval modes, snapshots, undo/restore, durable goals, agent teams, and file-based extensions are reusable patterns.
- **Evidence and maturity — 15/20:** Active MIT Rust project with releases, multiple installers, documentation, and community activity, though it is relatively new.
- **Novelty — 11/15:** Provider-neutral Rust TUI plus synchronized runtime API, workflow review, and local snapshots is a strong combination.
- **Risk-adjusted accessibility — 8/10:** Many install routes and local models help access, but granted host permissions and optional sandbox variability require care.
## Why it matters
- Its Plan, Ask, Auto-Review, and Full Access modes make authority changes legible to users.
- Durable goals, workflow review, undo/restore, MCP, and hooks form a practical long-task control surface.
## Caveat
The agent runs locally with the access granted to it; approval rules are not equivalent to an isolation boundary, and OS sandboxing is optional.
